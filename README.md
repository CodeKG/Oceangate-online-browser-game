# OCEAN GATE – Mission Titanic

Ein kleines Browser-Spiel in HTML, CSS und JavaScript. Keine Installation und keine externen Bibliotheken nötig.

## Spielen
- `index.html` im Browser öffnen.
- **W / Pfeil runter**: tiefer tauchen
- **S / Pfeil hoch**: auftauchen
- **A / D** oder **Pfeiltasten links/rechts**: seitlich steuern
- **Leertaste**: Drucksystem stabilisieren (gedrückt halten)
- Auf Mobilgeräten die Bildschirmtasten verwenden.

## Auf GitHub veröffentlichen
1. ZIP entpacken.
2. Ein neues GitHub-Repository erstellen.
3. `index.html` und `README.md` hochladen.
4. Optional: Unter **Settings → Pages** die Veröffentlichung über `Deploy from a branch` und den Branch `main` / Ordner `/ (root)` aktivieren.
5. Nach dem Speichern stellt GitHub Pages das Spiel unter deiner Repository-Adresse bereit.

## Hinweis
Das Spiel ist ein fiktives Arcade-Spiel und keine realistische technische Simulation. Das gezeichnete Tauchboot ist eine stilisierte Annäherung an das äußere Erscheinungsbild der OceanGate Titan, keine maßstabsgetreue oder technische Rekonstruktion.
